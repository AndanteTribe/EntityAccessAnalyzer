# EAA0002: 許可されていないpublicメソッド・演算子を公開しない

[English](EAA0002.md) | 日本語

| 項目 | 内容 |
| --- | --- |
| カテゴリ | EntityAccessAnalyzer |
| 標準重大度 | Error |

## メッセージ

> Entity '{0}' は禁止されたpublicメソッドまたは演算子 '{1}' を公開しています

`{0}`は対象Entity、`{1}`はメソッドまたは演算子です。

## 原因

Entityが、例外に該当しないpublicメソッドまたは演算子を公開しています。
staticメソッドやoverrideも対象です。

メソッド本体を解析して、読み取り専用かどうかを判定することはしません。
例えば、状態を変更しないpublicメソッドでも、許可された契約に該当しなければ診断します。

## 違反例

```csharp
namespace App.Entities;

public class Counter
{
    public int Value { get; private set; }

    public void Increment() => Value++;              // EAA0002
    public static Counter Create() => new Counter(); // EAA0002
}
```

## 修正例

状態変更メソッドの公開範囲を狭めます。生成にはpublicコンストラクターを使用できます。

```csharp
namespace App.Entities;

public class Counter
{
    public int Value { get; private set; }

    public Counter() { }

    internal void Increment() => Value++;
}
```

外部から呼び出すファクトリーやサービスが必要な場合は、Entityの対象名前空間外に配置します。
`internal`の操作を呼ぶサービスは、Entityと同じアセンブリなど、アクセス可能な場所に置きます。

## 許可されるメソッド

次のインターフェイスの対応メンバーを実装する場合は許可します。
単に同名のメソッドを定義しても例外にはなりません。

| 契約 | 対応メンバー |
| --- | --- |
| `IEquatable<T>` | `Equals` |
| `IComparable` / `IComparable<T>` | `CompareTo` |
| `IStructuralEquatable` | `Equals` / `GetHashCode` |
| `IStructuralComparable` | `CompareTo` |
| `IComparer` / `IComparer<T>` | `Compare` |
| `IEqualityComparer` / `IEqualityComparer<T>` | `Equals` / `GetHashCode` |
| `IFormattable` | `ToString` |
| `ISpanFormattable` / `IUtf8SpanFormattable` | `TryFormat` |
| `IParsable<TSelf>` / `ISpanParsable<TSelf>` / `IUtf8SpanParsable<TSelf>` | `Parse` / `TryParse` |

Parse系の実装はpublic staticメソッド禁止の例外です。
`TryFormat`が出力先として`Span<char>` / `Span<byte>`を引数に受け取ることは許可します。
これはEntity内部の書き込み可能なSpanを公開することとは区別します。

さらに、次を許可します。

- publicコンストラクター。
- `object.Equals(object)` / `object.GetHashCode()` / `object.ToString()`のoverride。
- 比較演算子`==`、`!=`、`<`、`>`、`<=`、`>=`。
- `implicit` / `explicit`変換。
- recordの`with`式に使用される合成コピー用メソッド。
- 分解用の`Deconstruct`。手書きも対象で、インスタンスメソッド、`void`戻り値、1つ以上の引数がすべて`out`であるもの。
- 明示的インターフェイス実装。

変換先と`Deconstruct`の出力型には[EAA0003](EAA0003.ja.md) / [EAA0004](EAA0004.ja.md)の規則を適用します。
許可メソッドの内部処理の純粋性までは検査しません。
上記の例外に該当しない算術・増減・複合代入などの演算子は原則禁止です。

`ICloneable.Clone`、`IDisposable.Dispose`、`IAsyncDisposable.DisposeAsync`のpublic実装は例外に含めません。
これらも明示的インターフェイス実装なら許可します。
