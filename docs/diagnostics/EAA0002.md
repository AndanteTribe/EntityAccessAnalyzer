# EAA0002: Do not expose prohibited public methods or operators

English | [日本語](EAA0002.ja.md)

| Property | Value |
| --- | --- |
| Category | EntityAccessAnalyzer |
| Default severity | Error |
| Enabled by default | Yes |
| Code fix | None |
| Implementation status | Diagnostic definition only; detection logic is not implemented yet |

## Message

> Entity '{0}' exposes prohibited public method or operator '{1}'

`{0}` is the entity and `{1}` is the method or operator.

## Cause

An entity exposes a public method or operator that is not an allowed exception.
Static methods and overrides are also subject to this rule.

Method bodies are not analyzed to determine whether they are read-only.
Even a method that does not change state is reported unless it matches an allowed contract.

## Violation

The examples assume `[assembly: EntityAccessScope("App.Entities", "App.Entities.*")]`
is configured in another file. Each example is independent.

```csharp
namespace App.Entities;

public class Counter
{
    public int Value { get; private set; }

    public void Increment() => Value++;              // EAA0002
    public static Counter Create() => new Counter(); // EAA0002
}
```

Diagnostic comments show the expected behavior once detection is implemented.

## Fix

Restrict access to state-changing methods. A public constructor may be used for creation.

```csharp
namespace App.Entities;

public class Counter
{
    public int Value { get; private set; }

    public Counter() { }

    internal void Increment() => Value++;
}
```

Place public factories or services outside the namespaces selected for entities.
A service calling an `internal` operation must be in an assembly that can access it,
such as the entity's own assembly.

## Allowed methods

Implementations of the following interface members are allowed.
A method with the same name alone does not qualify.

| Contract | Members |
| --- | --- |
| `IEquatable<T>` | `Equals` |
| `IComparable` / `IComparable<T>` | `CompareTo` |
| `IStructuralEquatable` | `Equals` / `GetHashCode` |
| `IStructuralComparable` | `CompareTo` |
| `IComparer` / `IComparer<T>` | `Compare` |
| `IEqualityComparer` / `IEqualityComparer<T>` | `Equals` / `GetHashCode` |
| `IFormattable` | `ToString` |
| `ISpanFormattable` / `IUtf8SpanFormattable` | `TryFormat` |
| `IParsable<TSelf>` / `ISpanParsable<TSelf>` / `IUtf8SpanParsable<TSelf>` | `Parse` / `TryParse` |

The parsing contracts are exceptions to the prohibition on public static methods.
`TryFormat` may accept a destination `Span<char>` / `Span<byte>`; writing to a caller-provided
destination is distinct from exposing a writable span into entity state.

The following are also allowed:

- Public constructors.
- Overrides of `object.Equals(object)`, `object.GetHashCode()`, and `object.ToString()`.
- Comparison operators `==`, `!=`, `<`, `>`, `<=`, and `>=`.
- `implicit` / `explicit` conversions.
- Compiler-synthesized record copy methods used by `with` expressions.
- Deconstruction methods, including handwritten ones: instance `void Deconstruct` methods
  with at least one parameter, all of which are `out` parameters.
- Explicit interface implementations.

Conversion targets and `Deconstruct` output types are subject to [EAA0003](EAA0003.md) / [EAA0004](EAA0004.md).
The purity of allowed method bodies is not checked.
Other operators, including arithmetic, increment/decrement, and compound assignment operators,
are prohibited unless covered by an exception above.

Public implementations of `ICloneable.Clone`, `IDisposable.Dispose`, and `IAsyncDisposable.DisposeAsync`
are not exceptions. Explicit implementations of these interfaces are allowed.

## Configuration

```editorconfig
[*.cs]
dotnet_diagnostic.EAA0002.severity = error
```

Use `warning` to report a warning or `none` to disable this rule. For a local suppression,
use `#pragma warning disable EAA0002` and `#pragma warning restore EAA0002`.
